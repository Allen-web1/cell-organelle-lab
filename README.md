# 세포의 구조와 기능 탐구실

정적 화면을 GitHub Pages에서 제공하고 학생 답안과 채점은 Supabase에 저장하는 교육용 앱입니다.
`config.js`에 Supabase URL과 default Publishable key 또는 anon key를 입력하세요.
Supabase 서버 함수 `cell-api`와 데이터베이스를 먼저 등록해야 학생 제출과 교사 대시보드가 작동합니다.
서버용 Secret key / service_role key 또는 교사 비밀번호를 이 저장소에 올리지 마세요.

7페이지 활동, 교과서 그림을 활용한 원핵세포·진핵세포 비교 빈칸 활동, 교사와 함께 연습 각 1회와 학생 혼자 평가 각 1회, 총 15점 평가, 막 구조 마인드맵과 교사 서술형 채점을 지원합니다.

순서: 정보 입력 → 원핵·진핵세포 → 세포 소기관 배치 → 마인드맵 → 11개 세포소기관의 기능 → 정답과 점수 → 형성평가.
배점: 비교 3점 + 배치 2점 + 마인드맵 2점 + 기능 3점 + 형성평가 5점. 연습은 수행평가 점수에 포함되지 않습니다.
GitHub Settings → Pages → Deploy from a branch → main / (root)로 배포하세요.

교사 대시보드는 학번·이름을 별도 열로 표시하고, 교사 채점까지 완료된 최종 총점 CSV 다운로드와 학번 확인 후 학생 기록 삭제를 지원합니다.
